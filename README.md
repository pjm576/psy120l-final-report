# University Prestige and Source Credibility: Moderating Roles for Need for Cognition and Trust in Science and Scientists
This repository contains the published HTML version of myPSY 120L final reproducible report.
This study examined whether a university’s name influenced perceived credibility of the university’s research on a health topic, and whether credibility ratings differed by need for cognition (NFC), trust in science and scientists (TIS), and their interactions with university prestige.
The report was created using Quarto and R.
The published report file is index.html.
The dataset is not included in this repository.
